HOW TO ENTER A CODE

Open Cheat codes from the game's main menu, type the code, and press Enter.

Codes ignore capital letters and spaces, so Unlock Level Five works. Codes only unlock content. They never add coins or credits; those come from playing.

LEVEL CODES

Each level has its own code: unlocklevel followed by the level number spelled out. A level code opens that one level to play. It does not mark the level cleared and does not open the level after it, so you still earn the rewards by winning the fight.

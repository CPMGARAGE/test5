THE STORY SO FAR

You start at Boot Camp and finish at the Master's Citadel.

The Tournament is a road of twenty duels. Early guards teach you wind and power. Along the way you take on a glacier, a toxic marsh, a hall of mirrors and a graveyard shift, and each rival leaves you a tank and a shell to keep. Level 17, the Gatekeeper, is described in the game as the last guard on the Master's road.

The final three levels are the Master's own ground: the Forge, the Storm Spire and the Citadel, where the game calls the last duel one fought on ground few have seen. Win there and the Master difficulty, the Sovereign tank and the Aurora shell are yours.

THE INVASION

The missions tell a second story. They start as marathons against fresh opponents and grow into co-op fights, and then a saucer appears over the field with shields, hops and three-shot volleys. From the Scout to the Destroyer to the Overmind, the UFO fights get bigger until the last mission, the Mothership, where the alien flagship arrives with two drones and, as the game puts it, everything you have learned is needed at once.

HOW IT IS BUILT

TerminalTanks is one Python file of about 8,900 lines. It needs Python 3.10 or newer and a UTF-8 terminal of at least 96 by 28 characters. It uses no third-party packages: drawing, input and animation are all built on the standard library and plain ANSI escape sequences.

RenderingANSI escape sequences, no curses MultiplayerLAN play over TCP, with UDP discovery so hosts appear on their own FairnessThe simulation is seeded and deterministic, and visual effects use their own random generator so they cannot change an outcome SavesOne small JSON file, versioned, with migration for older saves In the browserThe same game file, using its built-in web backend, on the Pyodide Python runtime with a hand-written canvas renderer

The deterministic design is what makes LAN play work: both machines run the same simulation from the same starting setup, so a shot only needs to send its angle and power. It also keeps matches reproducible.

HOW THE BROWSER VERSION WORKS

The browser version runs the same terminaltanks.py as the terminal, but it is not literally untouched. The file contains a web backend that sends the screen to the page as a grid of cells instead of ANSI text, and the page stubs the few operating-system terminal modules the game imports. Scenes, physics, AI and saves are the same code in both places.

The page draws that grid with its own canvas renderer, with no terminal library and no other third-party code. The one outside piece is Pyodide, the Python runtime itself, which downloads on your first visit (about 10 MB) and is cached after that. The game and its renderer still follow the project's rule of no dependencies of their own.

Saves have changed shape over time. The game still reads version 1 to 3 files and converts them. For example, the old Master fight at level 5 now lives at level 20, and its rewards carry over.

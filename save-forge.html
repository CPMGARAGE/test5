BUILD A SAVE FILE

Pick what you want unlocked and download a backup file the game can import.

Open the game, choose Save data, then Import backup. Importing replaces the save on that device. To keep your real progress, settings and loadouts, load your own backup below and edit that instead of starting from nothing. Everything runs in this page; nothing is uploaded.
